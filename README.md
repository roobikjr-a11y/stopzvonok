# Стоп-звонок 🔒📞

Тренажёр безопасного разговора для защиты людей старшего возраста от телефонного мошенничества.
Учебный социальный проект по дисциплине «Безопасность жизнедеятельности», НИУ ВШЭ, МИЭМ.

## Что это

Веб-сайт-тренажёр: пожилой человек в безопасной обстановке «проживает» звонок мошенника,
выбирает варианты ответа и получает мгновенную обратную связь — как симулятор вождения,
только для телефона. Без регистрации и установки приложений, крупный шрифт и высокий контраст.

## Разделы

- **Тренажёр звонка** — 3 интерактивных сценария с ветвлением:
  «служба безопасности банка», «следователь полиции», «техподдержка/Госуслуги»
- **Квиз** — 10 вопросов с пояснениями к каждому ответу
- **Памятка** — «пять железных правил»
- **Страница для близких** — 6 шагов, как защитить пожилых родных

## Технологии

Чистый HTML/CSS/JS, один файл `index.html`, без зависимостей и сборки.
Открывается локально или на любом статическом хостинге (GitHub Pages и т.п.).

- ВЦИОМ + Минцифры (2026): 98% получают нежелательные звонки, 65% — и спам, и мошенников
- Банк России (2026): пенсионеры — наибольшая доля потерявших свыше 1 млн ₽
- РБК (2025): 93% атак на пожилых начинаются с телефонного звонка
